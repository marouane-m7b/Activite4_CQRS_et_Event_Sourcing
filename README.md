# CQRS et Event Sourcing

Projet pédagogique de gestion de comptes bancaires avec **Spring Boot**, **Axon Framework**, CQRS et Event Sourcing. L’implémentation suit les écrans et signatures lisibles dans les captures de la vidéo.

> **État :** en cours. Les prochaines étapes suivent les captures; aucune fonctionnalité non représentée n’est ajoutée.

## Stack visible dans les captures

- Java et Maven
- Spring Boot 2.7.6
- Axon Framework 4.6.1
- Spring Web, Spring Data JPA et MySQL
- Lombok, Springdoc OpenAPI et MapStruct

## Démarrage

Le projet utilise Maven Wrapper. La configuration et les endpoints seront documentés au fur et à mesure des étapes implémentées.

Les captures et outils temporaires utilisés pour l’extraction sont conservés localement dans `video_extract/` et exclus du dépôt.
